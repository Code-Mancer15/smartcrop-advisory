# 🌾 SmartCrop Advisory System

An AI-powered crop recommendation system using Machine Learning and Spring Boot.

## 🚀 Features

* Crop prediction using Naive Bayes (Weka)
* Fertilizer recommendation
* Weather-based farming advice
* User signup system
* Interactive charts (Chart.js)

## 🧠 Tech Stack

* Java
* Spring Boot
* Weka (Machine Learning)
* Thymeleaf
* H2/MySQL
* Maven

## ▶ How to Run

```bash
mvn clean install
mvn exec:java
mvn spring-boot:run
```

Open: http://localhost:8080
